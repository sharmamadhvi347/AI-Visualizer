How it works

State Space Search: The problem is modeled as a graph where each node is a state (M_left, C_left, Boat_pos). BFS (Breadth-First Search) explores all valid moves layer by layer, ensuring we find the shortest safe path, which optimally takes 11 moves. A state is invalid if Cannibals outnumber Missionaries on either bank (unless M=0).

How it works

Nearest Neighbor (Greedy): A heuristic algorithm that starts at a random city and repeatedly visits the nearest unvisited city. It's fast (O(N²)) but doesn't guarantee the absolute shortest route.

2-Opt Optimization: An iterative improvement technique that untangles crossed paths by swapping two edges if the swap reduces the total distance, fine-tuning the greedy result.
